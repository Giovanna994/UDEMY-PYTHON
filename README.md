# Python

Repositório dedicado aos meus estudos e práticas realizados ao longo do curso **Python 3 do Zero ao Avançado** (Udemy). Aqui você encontrará códigos, exercícios práticos, projetos e notas de aprendizado cobrindo desde a sintaxe básica até tópicos avançados de desenvolvimento em Python.

---

## 📌 Sobre o Curso

O curso aborda a linguagem Python do básico ao avançado, combinando teoria, boas práticas de código (PEP 8) e projetos práticos.

* **Curso:** [Python 3 do Zero ao Avançado](https://www.udemy.com/course/python-3-do-zero-ao-avancado/)
* **Plataforma:** Udemy
* **Linguagem:** Python 3.x

---

## Conteúdo e Módulos Estudados

- [x] **Fundamentos de Python & Lógica de Programação**
  - Tipos de dados, variáveis, operadores aritméticos e lógicos
  - Estruturas condicionais (`if`, `elif`, `else`)
  - Estruturas de repetição (`while`, `for`)
  - Manipulação de strings e f-strings

- [x] **Estruturas de Dados**
  - Listas (`list`), Tuplas (`tuple`), Dicionários (`dict`) e Conjuntos (`set`)
  - Compreensão de listas (*List Comprehension*) e dicionários
  - Funções built-in e iteração

- [x] **Programação Funcional & Modularização**
  - Definição de funções (`def`), parâmetros `*args` e `**kwargs`
  - Funções de alta ordem, expressões `lambda`, `map`, `filter`, `reduce`
  - Criação de módulos e pacotes (`pip`, `virtualenv`)

- [x] **Programação Orientada a Objetos (POO)**
  - Classes, Objetos, Métodos e Atributos
  - Encapsulamento, Herança, Polimorfismo e Abstração
  - Métodos de classe, estáticos e propriedades (`@property`)
  - *Dunder methods* (métodos mágicos)

- [x] **Tópicos Avançados & Módulos Úteis**
  - Tratamento de exceções e erros (`try`, `except`, `finally`)
  - Manipulação de arquivos (`JSON`, `CSV`, TXT)
  - Datas e horas com `datetime`
  - Automação, raspagem de dados (*web scraping*) e banco de dados (SQLite/MySQL)
